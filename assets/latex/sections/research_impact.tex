    \cvSubheading{Open-Source Systems and Benchmarks}
    \begin{list}{\textbullet}{\setlength{\leftmargin}{1.2em}\setlength{\labelwidth}{0.7em}\setlength{\labelsep}{0.35em}\setlength{\itemsep}{0.12em}\setlength{\parsep}{0pt}\setlength{\topsep}{0.1em}}
      \item \textbf{\cvlink{https://github.com/Xtra-Computing/FedTree}{FedTree}} (MLSys'23): an open-source federated learning system for tree-based models; it supports reproducible and privacy-preserving GBDT training across parties. 152 GitHub stars and 41 forks.
      \item \textbf{\cvlink{https://github.com/Xtra-Computing/VertiBench}{VertiBench}} (ICLR'24): a public benchmark for systematically evaluating vertical federated learning under varying feature-diversity settings; it standardizes evaluation beyond single synthetic data splits and is released as an installable PyPI package.
      \item \textbf{\cvlink{https://huggingface.co/datasets/Jerrylife/WikiDBGraph}{WikiDBGraph}} (ICDE'26): a large-scale database graph of Wikidata for collaborative learning; it releases 100{,}000 database nodes and 17 million edges for database-silo learning research.
      \item \textbf{\cvlink{https://github.com/Xtra-Computing/LLM-DNA}{LLM DNA}} (ICLR'26 Oral): an open-source toolkit for extracting functional DNA signatures and tracing LLM evolution from model behavior, with a public project website and PyPI package.
      \item \textbf{\cvlink{https://github.com/Xtra-Computing/OARF}{OARF}} (ACM TIST'22): a benchmark suite for characterizing federated learning systems; it provides reusable workloads for system-level FL comparison.
    \end{list}
